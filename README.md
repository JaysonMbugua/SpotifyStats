# SpotifyStatsViewer 🎧📊

SpotifyStatsViewer is a personalized music insights app built with SwiftUI. It connects with the Spotify Web API to display your listening habits — including your top tracks, favorite artists, recent playback, and genre trends — all in a clean, interactive interface.

##  Features

- **Secure Spotify Login**  
  OAuth 2.0 authentication using PKCE, with a secure redirect URI.

-  **Top Tracks & Artists Dashboard**  
  View your most listened-to songs and artists for the week, month, or year.

-  **Now Playing & Recently Played Library**  
  Shows what you're listening to now, and stores a history of recently played tracks.

-  **User Search & Playlist Explorer**  
  Search any Spotify user by ID and browse their public playlists.

-  **Track Detail View**  
  Tap any track for a detailed view with album art, artist info, and links to open in Spotify.

-  **Light & Dark Mode Support**  
  Full dynamic styling that adapts across system appearance modes.

-  **Offline Storage with SwiftData**  
  Recently played tracks are stored locally and persist between sessions.

##  Built With

- **SwiftUI** – Declarative UI framework for native iOS interfaces  
- **Spotify Web API** – Retrieves real-time user data and music metadata  
- **URLSession** – Used for secure networking and API requests  
- **SwiftData** – Persists recently played track history offline
